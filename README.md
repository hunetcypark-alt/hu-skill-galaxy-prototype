# HU 스킬 갤럭시 프로토타입

스킬·콘텐츠·커리어 연관 관계를 탐색하는 HU 스킬 갤럭시 화면 시안 (단일 HTML, 예시 데이터).

- 열기: `index.html`을 브라우저에서 열면 됩니다 (빌드 없음).
- 데이터: 예시 데이터(스킬 16·커리어 7·콘텐츠 17). 실데이터 연결 전 단계입니다.
- 펼침 기준: 연관도 0.8 이상 · 높은 순 · 도메인당 최대 10개, 더보기로 10개씩 (샘플 점수는 보정값 적용).
- PC 우선, 모바일(≤760px)은 1차 대응.

시안 공유
	•	승모님: 지도형 스킬갤럭시
	◦	준호팀장님: 의도를 아는 사람은 찾아갈 수 있으나 맵이 무엇을 의미하는지는 잘 모르겠다.
	•	주안님: 경로형 스킬갤럭시
	◦	경로를 공유할 수 있는 기능 추가
	▪	하나의 여정을 통해 유저의 학습 참여를 도울 수 있도록 하기 위함
	▪	부사장님: 최근 검색어를 저장하는가? 경로를 둔다고 해서 근본적인 문제(복잡함)가 해결되는가
	▪	준호팀장님: 클릭을 하는 순간에 내가 이전에 열어둔 내용을 알려주는 용도
	◦	시작점을 좀 더 쉽도록 돕는 AI 채팅 기능 추가
	◦	노드 연결 선 hover 시 연관도 수치를 함께 보여줌
	◦	기존 스킬, 커리어의 상세 페이지는 노드 클릭 시 보여지도록 변경

핵심
	•	리스팅을 했을 때 보여줄 수 있는 정보와 갤럭시에서 보여줄 수 있는 정보의 관계
	◦	여러 개의 축을 가장 잘 보여줄 수 있는 방법은 카메라를 들고 멀리서 보는 것 (연관도를 나타낼 방법이 멀리서 한 번에 보여주는 것) = 갤럭시
	◦	전혀 다른 4개의 축을 연결을 시켜두었다 라는 것이 핵심 (공간화)
	◦	기술적 한계: 기준이 되는 노드의 연관도는 구할 수 있는데, 새로운 노드가 생겼을 때 기존에 그려진 부분을 다시 그리기 어렵다는 것
